For GeoGebra Classic 6 on macOS and Windows

Claude, right inside GeoGebra.

Right-click a function, a point or an empty spot on the graph. Claude explains it, analyses it, or draws what you ask, working on your live construction. Everything else in GeoGebra stays exactly as it was.

Free and open source. You bring your own Anthropic API key.

It works on your construction.

Claude uses GeoGebra's own commands and CAS, then looks at the drawing to check the result.

Discreet by design.

Right-click anything

Explain, analyse, or ask about any object, from the graph or the Algebra view. Right-click empty space to draw something new there.

Real GeoGebra commands

Claude runs input-bar commands, checks the maths with the CAS, styles and deletes objects, and moves the view.

One-step undo

Everything Claude changed in a reply comes back with a single Undo. You always see what it ran.

Your model, your effort

Pick Claude Sonnet 5.5 or Opus 5.5, and the effort from low to max. Reasoning summaries and a read-only mode are one switch away.

Keyboard first

⌘K quick ask, ⌘J side panel, ⌘, settings. On Windows it is Ctrl instead of ⌘.

Your key stays yours

Stored encrypted in the macOS Keychain or Windows' per-user encryption, and sent only to Anthropic. No account, no middleman.

Speaks Norwegian when GeoGebra does: the menu reads Forklar f med KI, and Claude answers in the language you write in.

Install in a minute.

GeoSmart patches the GeoGebra Classic 6 you already have. Quit GeoGebra first.

macOS

  1. Install GeoGebra Classic 6 into Applications.
  2. Download GeoSmart for Mac and unzip it.
  3. Right-click Install GeoSmart.command and choose Open. It asks for your Mac password.
  4. Open GeoGebra, press ⌘, and paste your API key.

Windows

  1. Install GeoGebra Classic 6 from geogebra.org. The Microsoft Store version can't be patched.
  2. Download GeoSmart for Windows and extract it.
  3. Double-click Install GeoSmart.cmd. No admin rights needed.
  4. Open GeoGebra, press Ctrl+, and paste your API key.

When GeoGebra updates, run the installer again. To remove GeoSmart, run Uninstall GeoSmart and the original files come back.

What it changes.

Small, visible and reversible.

A backup firstGeoGebra's original main.js, preload.js and pages are saved next to them, and Uninstall puts them back.
A few hooksOne line loads GeoSmart in the main process, a small bridge is added to the preload script, and each page loads the GeoSmart panel and KaTeX.
Calls go directRequests go from your computer straight to the Anthropic API with the official SDK. Nothing passes through a GeoSmart server.
On macOSThe app is re-signed ad-hoc, which also takes it out of the App Store sandbox, so GeoGebra's own settings start fresh once.
