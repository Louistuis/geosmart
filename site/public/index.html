GeoSmart

Claude, inside GeoGebra.

Right-click a function, a point or an empty spot in GeoGebra Classic 6. Claude explains it, analyses it or draws what you ask, in your own construction.

Set up Learn more

GeoGebra's own right-click menu, with three items added at the bottom.

Set up

One command. Done.

Install GeoGebra Classic 6 first. The command downloads the latest GeoSmart, closes GeoGebra if it is open and adds Claude to it.

Paste in Terminal

curl -fsSL https://gs.lou15.com | bash
  1. Get GeoGebra Classic 6 from the App Store. Skip this if you have it.
  2. Open Terminal, paste the command and press Return. It asks for your Mac password once.
  3. In GeoGebra, press ⌘ , and paste your Anthropic API key.

To remove GeoSmart: curl -fsSL https://gs.lou15.com/uninstall | bash
Or download GeoSmart-macOS.zip and open Install GeoSmart.command.

Paste in PowerShell

irm https://gs.lou15.com | iex
  1. Get GeoGebra Classic 6 from geogebra.org. The Microsoft Store version cannot be changed.
  2. Open PowerShell from the Start menu, paste the command and press Enter. No administrator rights needed.
  3. In GeoGebra, press Ctrl , and paste your Anthropic API key.

To remove GeoSmart: irm https://gs.lou15.com/uninstall | iex
Or download GeoSmart-Windows.zip and open Install GeoSmart.cmd.

Read the scripts first: install.sh and install.ps1. Run the command again after GeoGebra updates.

In practice

It works on your construction.

Claude uses GeoGebra's own commands and CAS, then looks at the drawing to check its work. Every command it runs is listed, and one click undoes them all.

Analyse f: the turning points come from the CAS, the marks are ordinary GeoGebra objects.

Features

Quiet until you need it.

GeoGebra looks and works exactly as before. Claude is one right-click or one shortcut away.

Right-click anything

Explain, analyse or ask about any object, in the Graphics or the Algebra view. Right-click empty space to draw something new there.

Real GeoGebra commands

Claude defines objects, checks maths with the CAS, styles and deletes objects and moves the view, all through GeoGebra itself.

Undo in one step

Everything Claude changed in a reply is reverted with a single Undo.

Sonnet or Opus

Choose Claude Sonnet 5.5 or Opus 5.5 and the effort, from low to max. Reasoning summaries and a read-only mode are in Settings.

Shortcuts

⌘ K to ask, ⌘ J for the panel, ⌘ , for settings. Ctrl on Windows.

Your key, kept private

Stored encrypted in the macOS Keychain or with Windows user encryption, and sent only to Anthropic. No account, no server in between.

Under the hood

What the setup changes.

Small, visible and reversible. The source is on GitHub.

  • A backup firstGeoGebra's original main.js, preload.js and pages are saved next to them. Uninstalling puts them back.
  • A few hooksOne line loads GeoSmart in the main process, a small bridge joins the preload script, and each page loads the panel and KaTeX.
  • Direct to AnthropicRequests go from your computer to the Anthropic API through the official SDK.
  • On macOSThe app is re-signed ad hoc, which also takes it out of the App Store sandbox, so GeoGebra's own settings start fresh once.
